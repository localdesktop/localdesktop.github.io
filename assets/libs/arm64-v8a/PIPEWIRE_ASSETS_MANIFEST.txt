Note: libpipewire-module-access.so was patched to need libglib-2.0.so instead
of libglib-2.0.so.0 so Android's native library extraction can ship it with a
standard `.so` filename.

Note: WirePlumber binaries and modules were patched for Android native library
extraction as well. Versioned NEEDED entries such as libgio-2.0.so.0,
libglib-2.0.so.0, libgobject-2.0.so.0, libgmodule-2.0.so.0,
liblua5.4.so.5.4, and libz.so.1 were rewritten to the flat `.so` names listed
above.

Note: wireplumber-share.tar contains the WirePlumber policy/config share tree.
The app extracts it into pipewire-standalone-aaudio/share before launching
libwireplumber_exec.so. The directory is packaged as a tar file because the
Android build path accepts regular asset files, not nested generated asset
directories.

Note: libpipewire_pulse_exec.so and libpipewire-module-protocol-pulse.so provide
PipeWire's PulseAudio-compatible protocol service. This is not the standalone
PulseAudio daemon; Firefox/libpulse clients connect to /tmp/pulse/native in the
guest and are translated into normal PipeWire streams.
